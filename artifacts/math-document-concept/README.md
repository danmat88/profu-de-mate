# Concept: document matematic unificat

Acest artefact este separat de aplicație și nu schimbă niciun ecran de producție.

Deschide `index.html` pentru planșa completă sau folosește unul dintre aceste URL-uri pentru un singur ecran:

- `index.html?screen=lesson`
- `index.html?screen=problem`
- `index.html?screen=summary`
- `index.html?screen=notebook`

Prototipul folosește MathJax 4 din CDN doar pentru demonstrație. Implementarea aplicației ar include rendererul, configurația și fonturile local, fără dependență de CDN.
