# Profu’ de mate — icon system prompts

Generated with the built-in image generation tool. Each icon was generated separately on a genuinely transparent background, then downsampled non-destructively from the `-v1.png` original to the `-ui.png` production asset.

## Shared production prompt

Use case: logo-brand

Asset type: one transparent mobile-app UI icon in the same original illustrated family for “Profu’ de mate”

Style/medium: bold flat 2D editorial sticker icon, hand-inked midnight-indigo outline with subtle line wobble, clean vector-like silhouette, tiny risograph grain only inside colored shapes, clever and energetic but not preschool-like

Color palette: midnight indigo `#171337` dominant outline, electric violet `#7C3CFF`, acid lime `#D8FF3E`, warm off-white `#FFF8EC`, optional tiny peach `#FF9273` accent

Composition/framing: exactly one isolated object-group centered in a square canvas, 18% transparent padding, strong silhouette, readable at 28–64 px

Scene/backdrop: genuinely transparent alpha background; no tile, circle, badge, shadow rectangle, scene, or environment

Constraints: no words, letters, numbers, formula, watermark, unrelated object, generic thin-line icon, emoji, 3D, glossy plastic, or photorealism; consistent thick outline and visual weight
